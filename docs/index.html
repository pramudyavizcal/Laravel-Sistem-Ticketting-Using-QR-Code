Sistem QR E-Ticket Multifungsi

Sebuah solusi manajemen event modern yang memungkinkan penyelenggara (Admin) mengelola event, pendaftaran, dan verifikasi tiket menggunakan teknologi QR Code secara instan.

Tech Stack

Laravel 12 (Stable) PHP 8.4 MySQL Database Vanilla CSS (Premium Design) Xendit PHP SDK v7 Bacon QR Code GuzzleHTTP

Aplikasi ini dibangun menggunakan arsitektur MVC (Model-View-Controller) standar Laravel untuk skalabilitas dan keamanan tinggi. Menggunakan database relasional untuk menyimpan data event, peserta, dan scan logs secara real-time.

Fitur Unggulan

Multi-Event Management

Kelola banyak event sekaligus dalam satu dashboard admin yang intuitif.

Paid & Free Events

Dukungan tiket berbayar dengan harga kustom dan tiket gratis.

QR Code Generation

Generate tiket unik dengan QR Code secara otomatis setelah disetujui.

Email Notifications

Notifikasi email otomatis untuk pendaftaran, persetujuan, dan penolakan.

Xendit Integration

Pembayaran otomatis via E-Wallet, VA, dan Retail dengan konfirmasi instan.

Admin QR Scanner

Scanner berbasis browser untuk verifikasi kehadirian peserta dengan cepat.

Panduan Penggunaan (Admin)

1. Membuat Event
Buka menu Events > Add New. Masukkan detail event, kuota, warna tema, dan tentukan apakah event tersebut berbayar atau gratis.
2. Konfigurasi Pembayaran
Pada halaman Edit Event, Anda bisa memilih metode pembayaran: Transfer Bank (manual) atau Xendit (otomatis).
3. Mengelola Pendaftaran (Attendees)
Pada menu Attendees, Anda akan melihat daftar pendaftar. Klik tombol Approve untuk menyetujui (tiket akan terkirim ke email peserta) atau Reject untuk menolak beserta alasan.
4. Dashboard Statistik
Lihat ringkasan total event, jumlah pendaftar, dan notifikasi pendaftaran yang butuh persetujuan cepat (Pending Approvals).

Panduan Penggunaan (Peserta)

1. Pendaftaran
Pilih event aktif di halaman utama, klik Daftar Sekarang, dan isi formulir data diri secara lengkap.
2. Pembayaran (Event Berbayar)
Jika event berbayar, peserta akan diarahkan ke halaman instruksi. Bisa pilih Bayar Sekarang (Xendit) untuk proses instan atau upload bukti transfer manual.
3. Menerima Tiket
Setelah disetujui Admin (atau otomatis lunas via Xendit), peserta akan menerima email berisi Tiket Digital dengan QR Code unik.

Panduan QR Scanner

Admin dapat menggunakan fitur Scanner bawaan untuk absensi di lokasi event:

  • Buka menu Scanner di Dashboard Admin menggunakan Smartphone atau Laptop dengan kamera.
  • Arahkan kamera ke QR Code milik peserta.
  • Sistem akan memvalidasi data dan menampilkan status (Success/Already Claimed/Invalid).

Integrasi & Setup

Email SMTP

Untuk mengirim email, atur file .env Anda:

MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=465
MAIL_USERNAME=email@anda.com
MAIL_PASSWORD=paskod-aplikasi

Xendit Webhook

Agar konfirmasi pembayaran otomatis berjalan, atur Webhook URL di dashboard Xendit (Callback) ke:

https://domainanda.com/api/webhooks/xendit
